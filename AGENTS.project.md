# Owner rules — Capital Misallocation / longshort

This is Ben's product. Chat instructions override sandbox defaults.

## Stop and ask

- Do **not** make design, formatting, layout, copy, or structural decisions without asking **1–2 clarifying questions** first and **waiting for approval**.
- Do **not** take off on a new tab, chart type, data source, or visual system because it “seems right.”
- If the user already named the exact change (“transparent legend, smaller type, stop clipping hints”), implement **only** that. Do not expand.
- Unsure between two layouts? Ask. Do not pick.

## Charts

- Legends: transparent background, 11px, never a floating opaque box over the plot.
- Do not invent spatial-optimizer libraries. Reserve margin for the legend; wrap labels; do not clip stat hints.
